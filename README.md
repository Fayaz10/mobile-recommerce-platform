# 📱 Mobile Recommerce Platform

A full-stack Mobile Recommerce Platform built using **Java Spring Boot**, **React.js**, **Material UI**, and **MySQL**.

The application allows customers to purchase certified refurbished mobiles, book repair services, and manage their orders. It also includes a complete Admin Panel for managing products, brands, device models, repair bookings, and customer orders.

---

## 🚀 Features

### Customer

- User Registration & Login
- JWT Authentication
- Browse Refurbished Mobiles
- Product Details
- Shopping Cart
- Checkout

- Repair Booking
- Profile Management

### Admin

# ⚙ Installation

## Backend

```bash
cd Mobile-Recommerce-Backend

mvn spring-boot:run
```

## Frontend

```bash
cd mobile-recommerce-frontend

npm install

npm run dev
```

---

# Database

Create MySQL database

```
mobile_recommerce
```

Update

```
application.properties
```

with your MySQL username and password.

# Build

Backend

Frontend
