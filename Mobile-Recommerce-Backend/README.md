# 📱 Mobile Recommerce Backend

A robust backend API for the Mobile Recommerce Platform built using Java Spring Boot. It provides secure authentication, product management, repair booking, order management, and RESTful APIs for the frontend application.

## 🚀 Features

- User Registration & Login
- JWT Authentication & Authorization
- Role-based Access Control (Admin & Customer)
- Product Management
- Mobile Brand & Model Management
- Repair Service APIs
- Order Management
- MySQL Database Integration
- RESTful APIs
- Spring Security
- Input Validation
- Exception Handling

## 🛠 Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- JWT Authentication
- Maven

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Fayaz10/mobile-recommerce-backend.git
```

2. Open the project in Eclipse or IntelliJ.

3. Configure MySQL.

4. Update:

```
application.properties
```

with your database credentials.

5. Run

```
MobileRecommerceApplication
```

6. The backend starts at

```
http://localhost:8080
```
